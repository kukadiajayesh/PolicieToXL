# cryptography (pulled in transitively by pdfminer.six) needs pinning because
# its 42.x+ series switched to a Rust toolchain that calls

# Windows build targets. requirements.txt has a platform_release-conditioned
# pin for this same reason, but that marker evaluates against the *build*
# machine, not the frozen target — it's a no-op when building on Windows
# 10/11/CI like this project always does, so the real pin has to live here
# instead, applied unconditionally. 41.0.7 is the last release built against
# the older (pre-crash) toolchain.
